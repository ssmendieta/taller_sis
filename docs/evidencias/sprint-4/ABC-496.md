# ABC-496 — Configuración de metas de KPI

Fecha: 23 de noviembre de 2026. Base integrada: `develop` en `60c3005`.

Se añadió `/kpis/metas` y el enlace «Metas de KPI», visibles con
`kpis.metas.gestionar`. La página consulta las cuatro configuraciones de cada
área mediante los endpoints existentes; además respeta el permiso de lectura
de Producción y el de Logística. No consulta un área sin autorización.

Cada formulario muestra unidad y sentido, permite editar meta y umbrales,
valida los límites del DTO y exige rojo mayor que amarillo. La meta vacía
envía `null`. Se muestran carga, errores, reintento, guardado y confirmación;
la respuesta del servidor actualiza el formulario.

## Validaciones ejecutadas

- `npm run test:metas-kpi`: 10 casos aprobados. Se montan rutas, página,
  componentes y clientes HTTP reales. La sesión y el backend son simulados.
  Cubren ocho configuraciones, contrato del PUT, nueva consulta al reabrir,
  eliminación de meta, validación, permisos por área, 401, 403 y reintento.
- Regresión de `kpis.test.mjs`, `dashboard-service.test.mjs`,
  `dashboard-logistica-service.test.mjs` y `sesion.test.mjs`: 21 casos aprobados.
- `npm run build`: compilación correcta; advertencia de tamaño del bundle.

Las pruebas de UI verifican el intercambio con una API simulada. No acreditan
por sí solas persistencia en la base de datos de presentación ni una revisión
visual en navegador. Para aceptación operativa: entrar con supervisor, editar
una meta, guardar y recargar; repetir con una cuenta sin permiso y comprobar
que no aparece la navegación ni se permite el acceso directo.
