## API `GET /api/logistica/historial/rutas/:id` (permiso `logistica.rutas.consultar`)

Devuelve `ruta` (fecha programada y original), `paradas` con su entrega y sus
boletas (número, estado, orden e ítems por lote), `lotes` con la cantidad
vigente (sin boletas anuladas), `incidencias` y `reprogramaciones`. Las cinco
lecturas filtran por la ruta pedida y se hacen en una transacción `REPEATABLE READ`.

```powershell
cd services/logistica-service
$env:LOGISTICA_DB_REAL='1'
npx jest src/historial
```

Resultado: **23 pruebas aprobadas, 0 fallidas** (`historial.detalle.spec.ts` y
las existentes del historial).
