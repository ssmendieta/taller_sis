# ABC-341 · Filtros y vista previa del reporte logístico

Verificación del 9 de noviembre de 2026 sobre `develop` en `6bffc7e`. La pantalla `/logistica/reportes` está disponible desde **Reportes logísticos** para cuentas con `logistica.rutas.consultar`.

Las fechas son obligatorias, inclusivas y admiten hasta 366 días. El estado de ruta filtra las rutas por su fecha programada. El estado de boleta filtra las boletas por su fecha de creación en Bolivia. La pantalla usa los totales y las cantidades decimales del servidor y muestra el período efectivo del reporte. Editar el formulario conserva la consulta mostrada. ABC-342 podrá reutilizar `reporte.filtros` y `parametrosReporteLogistico` para enviar los mismos parámetros a la exportación.

| Comprobación | Resultado |
| --- | --- |
| Vista previa logística | 9 pruebas aprobadas con sesión y HTTP simulados |
| Regresión de reportes de producción, historial de rutas y sesión | 32 pruebas aprobadas |
| Compilaciones de frontend y Logística | Correctas |
| Suites del endpoint de Logística | 27 pruebas aprobadas y 2 de persistencia omitidas. El adaptador PGlite de este entorno no aplicó el `search_path` de inicio que usa ese esquema temporal |
| Integración con Auth, Producción, Logística y gateway | HTTP 401 sin sesión, 403 sin permiso, 400 sin fechas y 200 para consultas con datos, filtradas y vacías |

La integración ejecutó las migraciones de los servicios en bases PGlite desechables. Una sesión Supervisor consultó una ruta con dos paradas, tres boletas y dos incidencias. La boleta anulada no contó como entregada. Las dos emitidas sumaron `2.1250 kg` y `3.5000 l` por separado. Al filtrar rutas `DESPACHADA` y boletas `ANULADA`, se obtuvo una boleta y ninguna ruta. Un período sin registros devolvió ambos listados vacíos.

Se montaron la ruta y el formulario reales con React Test Renderer y se ejecutaron las tres consultas por el gateway. La vista mostró el resultado completo, el filtrado y el vacío. La revisión visual en navegador queda pendiente.

Para reproducir la regresión, desde `frontend`:

```powershell
npm run test:reportes-logisticos
npm run test:reportes-produccion
npm run test:historial-rutas
npm run test:session
npm run build
```

Para la revisión en navegador, abre **Reportes logísticos** con un Supervisor o Encargado de Logística que tenga permiso de consulta de rutas. Selecciona un período con datos y otro vacío. Cambia solo el estado de boleta y verifica que el período y el filtro de ruta mostrados correspondan a la consulta aplicada.
