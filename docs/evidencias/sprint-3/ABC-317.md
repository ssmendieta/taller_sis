# ABC-317 · Validación del registro de pérdidas de materia prima

Verificación del 9 de noviembre de 2026 sobre `develop` en `cda862a`. Cubre los criterios de ABC-74 con el formulario de ABC-316 y la API de ABC-315.

| Comprobación | Resultado |
| --- | --- |
| Suite de pérdidas en Producción | 48 pruebas aprobadas, 14 de persistencia en un esquema aislado de PGlite, sin omisiones |
| Suite del formulario | 9 pruebas aprobadas con la API simulada |
| Registro desde el formulario con la API | 2.1250 kg de harina registrados y visibles en la misma orden |

La prueba de persistencia compara los identificadores de orden y material por su valor y comprueba la cantidad decimal exacta. La prueba de eliminación usa una orden con merma y sin resultados de calidad, y exige que el rechazo provenga de `fk_perdida_mp_orden`. Para el material exige `fk_perdida_mp_material`.

## Prueba con Auth, gateway y Producción

Se aplicaron las migraciones a bases desechables en PGlite. Se inició sesión con Encargado de Producción y con Supervisor. El permiso `materiales.registrar_consumo` estaba presente en el primero y ausente en el segundo.

| Solicitud de registro | Resultado observado |
| --- | --- |
| Sin sesión | HTTP 401 |
| Supervisor sin permiso de registro | HTTP 403 |
| Cantidad cero o negativa | HTTP 400 en ambos casos |
| Motivo compuesto solo por espacios | HTTP 400 |
| Harina registrada en gramos cuando su unidad es kg | HTTP 400 |
| Orden inexistente | HTTP 404 |

Después de esos rechazos, la orden aún devolvía una lista vacía. Se montó `PerdidasMateriaPrima` con React Test Renderer y se envió el formulario contra el gateway con la sesión real de prueba. La interfaz mostró **Pérdida registrada**, el motivo **Derrame en mezcladora** y el autor. Al consultar nuevamente la API, se comprobó el registro con cantidad `2.1250`, unidad `kg`, autor autenticado y fecha del servidor. Una segunda orden siguió devolviendo `[]`.

Antes y después del alta, Calidad conservó 95 conformes y 5 defectuosos, y el inventario local conservó los 100 kg de harina. Se dieron de baja las cuentas de prueba en la base desechable. La comprobación del formulario se hizo mediante su componente real con HTTP y persistencia. La revisión visual en navegador queda pendiente.
