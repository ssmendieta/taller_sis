# ABC-354 — Pruebas con ERP simulado

**Historia:** ABC-115 — consulta de vehículos y choferes del ERP para planificar rutas.
**Tipo de validación:** simulada y local; no se conectó un ERP real.

## Alcance validado

La prueba ejercita el flujo HTTP real de Logística (controlador, validación de
parámetros, autenticación, cliente ERP y servicio), sustituyendo únicamente:

- el ERP por un servidor HTTP local controlado;
- Auth por un servidor HTTP local;
- la persistencia del respaldo por un `Map` en memoria.

El contrato utilizado es `recursos-logisticos.v1`:

```http
GET {ERP_RECURSOS_URL}/v1/recursos-logisticos?fecha=AAAA-MM-DD
Authorization: Bearer <token>
Accept: application/json
```

El contrato completo y sus límites están en
[`docs/integraciones/recursos-logisticos-v1.md`](../../integraciones/recursos-logisticos-v1.md).

## Casos comprobados

| Caso simulado | Resultado esperado y comprobado |
| --- | --- |
| Respuesta válida | Devuelve origen `ERP`, conserva las fechas y reemplaza la copia completa. |
| Timeout | Reintenta, devuelve origen `RESPALDO`, aviso `TIMEOUT` y mantiene la fecha previa. |
| Error HTTP 503 | Devuelve el respaldo con aviso `NO_DISPONIBLE`; no lo presenta como sincronización reciente. |
| Respuesta malformada | Rechaza la respuesta con `RESPUESTA_INVALIDA` y conserva la copia anterior. |
| Vehículo duplicado | Rechaza toda la respuesta, no duplica recursos ni reemplaza el respaldo. |
| Filtros | Aplica disponibilidad y capacidad mínima sin alterar los totales de la copia. |
| Fallo sin copia | Devuelve `503 RECURSOS_NO_DISPONIBLES` sin listas que puedan interpretarse como disponibilidad vacía. |

La prueba específica está en
[`recursos-logisticos.http.spec.ts`](../../../services/logistica-service/src/recursos-externos/recursos-logisticos.http.spec.ts).

## Límites de la simulación

- No valida disponibilidad, latencia ni credenciales de un ERP real.
- No prueba TLS, DNS, balanceadores ni infraestructura externa.
- La persistencia real de PostgreSQL se cubre en las pruebas de ABC-352; en esta
  prueba HTTP se usa memoria para controlar cada escenario.
- Consultar recursos no los reserva en el ERP.
