# Reglas Git - Proyecto Taller

## Ramas principales
- `main`: rama estable / producción
- `develop`: integración continua

## Ramas de trabajo
Convención: `feature/ABC-XXX-descripcion`
Ejemplos:
- `feature/ABC-158-estructura-base`
- `feature/ABC-159-auth-login`
- `feature/ABC-160-produccion-crud`

Tipos adicionales (si aplica):
- `fix/ABC-XXX-descripcion`
- `hotfix/ABC-XXX-descripcion`
- `docs/descripcion`
